## Region geometry and maintenance

- Canonical country/state/suburb geometry is `../data/regions/*-{coarse,medium}.pbf` (standard Geobuf, 2D, six-decimal coordinates). `data/regions/*-medium.pbf` are symlinks to canonical assets. iOS bundles synchronized regular-file copies of countries coarse/medium, states coarse, and suburbs medium. Small `*-source.json` provenance/quality reports and `region-names.json` remain JSON.
- Regenerate from the repository root with a Python environment containing `pip install -r ios/Scripts/requirements-regions.txt`, then `python ios/Scripts/prepare-country-boundaries.py`, `python ios/Scripts/prepare-state-boundaries.py`, or `python ios/Scripts/prepare-suburb-boundaries.py` as appropriate. Generation uses temporary GeoJSON, validates binary round trips (and suburb source deviation/coastal points), publishes only `.pbf` geometry, and synchronizes iOS/web resources and metadata. Each script supports `--validate-only` for local asset integrity checks without downloading. Source caches must be outside the repository or match ignored `data/regions/*-download-cache.json`.
- One-time offline migration of legacy geometry: `python ios/Scripts/region_pipeline.py --convert-existing`. This requires the old canonical GeoJSON inputs and preserves their coordinates rather than fetching new source data. Only delete legacy geometry after reviewing conversion results.
- The vendored schema is `../data/regions/geobuf.proto`, pinned to Mapbox Geobuf v4.0.0 with only the Swift naming prefix added; attribution is in `geobuf.LICENSE`. Generated Swift messages use SwiftProtobuf 1.33.3. Regenerate from the repository root with `python ios/Scripts/generate-region-protobuf.py` using a matching `protoc-gen-swift` and `protoc` on PATH (or Python `grpcio-tools` when `protoc` is unavailable). The wrapper marks generated declarations and conformance extensions `nonisolated` for the app's default MainActor isolation; do not replace it with a bare protoc invocation. No code generation is required during app builds.
- Shared Python-encoded interoperability fixture: `../data/regions/geobuf-fixture.pbf`. Regenerate with `python ios/Scripts/region_pipeline_test.py --write-fixture` (does not run tests). Python coverage is `python ios/Scripts/region_pipeline_test.py`; Swift coverage includes `GeobufRegionDecoderTests` and `RegionBoundaryTests`; web codec coverage is `lib/regions/geobuf.test.ts`. Do not run these test suites without authorization.
- `npm run regions:repair` is a read-only classification repair dry run using `DATABASE_URL` (or `.env.local`). `npm run regions:repair -- --apply` updates only changed region fields in guarded transactional batches. Never run either against a database without explicit user approval; review the dry-run report before approving apply.
- Changing geometry does not refresh cached `hex_details` rows automatically. Deploy the matching API data/classifier before a separately authorized repair.
- Focused static verification: `npx tsc --noEmit --incremental false` and ESLint on changed TypeScript files. Relevant test files are `lib/regions/country-regions.test.ts`, `region-hierarchy.test.ts`, `hex-details.test.ts`, and `repair-hex-details.test.ts`; do not execute test suites unless explicitly authorized.
